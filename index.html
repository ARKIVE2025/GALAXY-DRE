From a galaxy to a business

The ecosystem didn't start as a business site. It started as an experiment in how far one interface could go.

Then

Galaxy-DRE

A single-file, Three.js galaxy where every tool lived as a node you flew between. It was ambitious and it was memorable — but it asked visitors to explore before they understood what anything did.

The shift

Two chat systems retired

Chat with DRE and DRE Interface — the galaxy's AI chat layer — have been retired. They're no longer running. What they did is preserved below, in the legacy record.

Now

A site built to convert

Two clear products, a set of focused utilities, and a straight path from landing here to using something. Same tools, same theme — a front door that actually works.

GALAXY-DRE · V14 · ARCHIVED

The Galaxy Interface

Original ecosystem interface, retired

Before this site, the ecosystem lived inside a 3D galaxy built in Three.js. Every tool was a star you could fly to, open, and read about. It was the most ambitious thing we'd shipped — and it made a great first impression without making a great first conversion.

  • Navigable 3D field — drag, zoom, and orbit between tool nodes rendered as stars
  • Chat with DRE — a no-key-required AI strategy chat, retired along with this interface
  • DRE Interface — a bring-your-own-key AI terminal with multiple controller modes, also retired
  • Live data readout — a terminal-style overlay showing session and system stats
  • Intel Archive — a searchable knowledge base layered over the whole system
This is a historical record only. The interface shown here is not live and cannot be entered.
